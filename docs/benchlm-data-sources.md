# benchlm.ai 数据源参考

benchlm.ai 提供 benchmark 与价格性能数据，可作为后续「模型基准测试」功能的候选数据源。
注意：`_next/data/<buildId>/` 路径中的 buildId 会随对方站点重新构建而失效，使用前需重新抓取有效 buildId。

## 数据端点

- Providers: `https://benchlm.ai/_next/data/H6Iqsu_-OZisaI93y2eDo/providers.json`
- Models: `https://benchlm.ai/_next/data/H6Iqsu_-OZisaI93y2eDo/models.json`
- Benchmarks catalog: `https://benchlm.ai/_next/data/H6Iqsu_-OZisaI93y2eDo/benchmarks.json`
- Benchmark descriptions: `https://benchlm.ai/benchmark_descriptions.json`
- Pricing: `https://benchlm.ai/api/data/pricing`
- Leaderboard: `https://benchlm.ai/api/data/leaderboard`
- 价格性能: `https://benchlm.ai/_next/data/H6Iqsu_-OZisaI93y2eDo/llm-price-performance.json`
- 对比数据: `https://benchlm.ai/_next/data/H6Iqsu_-OZisaI93y2eDo/compare.json`
